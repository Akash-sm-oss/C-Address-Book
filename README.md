# C-Address-Book
A contact management system developed in C using structures, file handling ,and modular programming.

Features
1.Add new contacts
2.Search for contacts
3.Edit existing contact details
4.Delete contacts
5.Display the contact list
6.Validate phone numbers and email addresses
7.Store and manage contact using handling

Technologies Used
1.C Programming
2.Structures
3.Pointers
4.File Handling
5.Modular Programming
6.GCC Compiler

Project Structure
AddressBook/
├── .vscode/
├── delete/
├── display/
├── duplication/
├── edit/
├── include/
├── search/
├── src/
├── validation/
├── database.csv
└── README.md

Compilation
Run the following command from the project root directory:
gcc src/*.c validation/*.c display/*.c duplication/*.c -Iinclude -o addressbook

Execution
./addressbook

Learning Outcomes
The Project helped me practice modular C Programming,structures,pointers,file handling,input validation,and CRUD operations(Create,Read,Update,Delete).
